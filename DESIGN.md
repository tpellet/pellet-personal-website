# Design Decisions

## 2026-01-21 - Project Initialized

Project created from brief: "Personal website for professional use with resume sync, photo gallery, and publications"

### Initial Architecture

**Framework:** Hugo (static site generator)
- Fast build times
- Markdown-based content
- Zero runtime dependencies
- Excellent GitHub Pages support

**Hosting:** GitHub Pages
- Free, reliable hosting
- Automatic deployments via GitHub Actions
- SSL included

**Theme:** Custom "minimal-portfolio"
- Clean typography with Inter font
- Mobile-responsive design
- Generous whitespace
- Professional but not corporate

---

## 2026-01-21 - MVP Implementation

**Context:** Need a working portfolio with all core pages.

**Decision:** Build custom minimal theme rather than use existing Hugo theme.

**Rationale:**
- Complete control over design
- No dependency on external theme updates
- Exactly matches the minimalist aesthetic needed
- Simple enough to maintain

**Structure:**
- `/` - Landing page with bio and social links
- `/publications/` - List of articles (placeholder)
- `/gallery/` - Google Photos embed
- `/resume/` - PDF viewer with download link

**Alternatives considered:**
- Hugo themes like "PaperMod" or "Hugo Coder" - too opinionated
- Next.js - overkill for static content
- Plain HTML - harder to maintain

## 2026-10-07 — Portfolio redesign

Keep Hugo and serve static HTML. A portfolio needs a dependable content workflow and fast pages; its browser interactions do not need an application framework.

The visual identity uses mineral white, graphite, restrained lavender, and sage. Manrope carries the name and interface; Instrument Serif gives publication titles a distinct reading voice. Both fonts are served locally with their licenses. A deliberately composed production-network illustration connects the landing page to the published economics research. It is an illustration, not empirical data. The connection trace responds to a button; the only automatic motion is a brief entrance using locally served Motion 14.0.0.

Software descriptions come from public repositories, with authorship distinguished from contributions to a fork. Publication metadata lives in `data/publications.yaml` and supplies both the home page and research page. The empty gallery stays accessible at its existing URL and is omitted from primary navigation. The résumé PDF is unchanged and manually maintained.

All content and navigation remain usable without JavaScript. Keyboard focus, reduced motion, unavailable browser storage, missing animation code, narrow screens, and direct PDF access are checked in browsers. The light and dark themes respect the system preference until a visitor chooses one.

GitHub Pages remains the active host, with a pinned Hugo build and browser checks before deployment. Vercel configuration and Cloudflare Pages instructions use host-specific base URLs. Internal URLs are generated by Hugo so a move from the Pages subpath to a root domain does not require rewriting page content. Account connections are separate from configuration.

Pre-commit UBS scanning of authored browser code exits successfully. Scanning the unmodified minified Motion distribution exits 1: its 145 loose-comparison findings are `typeof` string comparisons, intentional null/undefined checks, and numeric remainders. Its seven reported undeclared assignments are not reproduced by TypeScript symbol resolution: every identifier assignment binds to a declared symbol. These vendor findings were reviewed as false positives; scanner rules were not changed, and the upstream distribution was kept intact.
